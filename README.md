# spacers-boutique

Caisse PWA des boutiques Spacer's (B1 Grand Public, B2 VIP) et tableau de bord de pilotage.

- `index.html` : caisse tablette, format paysage, hors ligne, scan des billets Tickie.
- `pilotage.html` : tableau de bord (spectateurs Tickie, CA, transformation, ventes reliées aux acheteurs).
- `apps-script/` : projet Apps Script « Pilotage Boutique » et sa notice d'installation.
